# Tamizharasi B — Portfolio

One-page portfolio for Tamizharasi B, physiotherapist pursuing an MPT in Neurology at Yenepoya (Deemed to be University), Bengaluru.

- `index.html` — the whole site (HTML, CSS and JS in one file)
- `portrait.jpg` — portrait used in the hero and opening sequence

No build step. Open `index.html` in a browser, or publish with GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root).

Fonts load from Google Fonts; GSAP 3.12.5 + ScrollTrigger from cdnjs and Lenis 1.1.13
(desktop smooth scrolling) from jsDelivr. The page still works if any of them is
unavailable, and visitors who prefer reduced motion get a still, fully readable page.

## Sections
Opening sequence · hero · about · education · clinical experience ·
my academic world (interactive: nerve signal, gait cycle, hamstring length) ·
research · achievements · workshops · skills · contact
