# Tamizharasi B — Portfolio

One-page portfolio for Tamizharasi B, physiotherapist pursuing an MPT in Neurology at Yenepoya (Deemed to be University), Bengaluru.

- `index.html` — the whole site (HTML, CSS and JS in one file)
- `portrait.jpg` — portrait used in the hero and opening sequence

No build step. Open `index.html` in a browser, or publish with GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root).

Fonts load from Google Fonts and the animation library (GSAP 3.12.5) from cdnjs;
the page still works if either is unavailable.
